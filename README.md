## 📖 简介

**小土去哪** 是一款以虚拟歌姬**星尘（Stardust）**为主题的打卡拍照 App。

打开相机，叠加星尘主题相框，拖动 / 缩放 / 旋转调整到满意位置，按下快门，一张专属打卡照就诞生了。拍照后自动保存到相册，还能在地图上查看你的所有打卡足迹。

## 🌟 功能一览

| 功能 | 说明 |
|------|------|
| 📸 拍照打卡 | 全屏摄像头预览，支持前后切换、闪光灯 |
| 🎨 星尘相框 | 内置主题相框，单指拖动、双指缩放、双指旋转 |
| 💾 自动保存 | 合成照片自动存入相册「星尘打卡」目录 |
| 📍 地图足迹 | 高德地图展示所有打卡点，点击查看大图 |
| 🔒 隐私保护 | 坐标随机偏移，地址自动脱敏，无需注册账号 |
| 🖼️ 更多打卡棒 | 打卡棒子资源热更新 无需重新安装 |
---

## 🗺️ 页面导览

**首页** — 深空蓝黑背景，星点闪烁，三个入口一目了然

**拍照** — 全屏预览 + 可交互星尘相框，随手拍出仪式感

**预览** — 合成 / 保存 / 上传一步到位，定位可开关

**地图** — 暗色主题高德地图，圆形照片标点，点击弹出大图卡片
